# damda-sources

담다 앱의 "오늘의 소재" 목록입니다. 앱이 `sources.json`을 읽어 보여 줍니다.

## 링크 올리는 법

`sources.json`의 `items`에 항목을 추가합니다.

```json
{ "id": "고유한-아무-글자", "url": "https://...", "title": "영상 제목", "category": "캠핑", "memo": "참고할 말", "addedAt": "2026-09-19" }
```

- `url`만 필수입니다. 유튜브·인스타그램·틱톡 링크 모두 됩니다.
- `category`가 같은 것끼리 묶여서 보입니다.
- 지우려면 그 항목을 삭제하면 됩니다. 앱에는 몇 분 안에 반영됩니다.
